# Historical engineering notes — 0.3.0

Pre-public application version, 14 October 2026. The earlier distribution was
GPL-3.0-or-later; earlier recipients retain those rights. These notes do not
announce a public tag or binary. Install the [current source edition](../../README.md)
and review [licensing](../licensing.md) before redistributing executables.

## Scope

- Seven workflow stages, persistent analysis choice, contextual inspector and
  Issues/Jobs/History drawer; Apply/Discard/Stay and read-only historical inspection.
- Immutable project-owned vertex editing, hierarchy-placement isolation, Undo/Redo,
  embedded edited-layout reopening and unchanged imported files.
- Five parameterized power-device example families preserving E1–E19, with compact,
  engineering and opt-in large presets and explicit resource/model limits.
- Exact nested measurement support and partial-element integration; explicit
  exceedance threshold/fraction migration; weak-link-preserving passive exports;
  actual-geometry via rules across interface groupings.
- Finite-feed ports, passive sensing, individual contact/via loading, device groups,
  named reservoirs and a disjoint loss ledger. Protected routing candidates require
  equal service, mesh evidence and actual exported-layout reimport before certification.

## Compatibility and limits

Ambiguous old exceedance configurations require explicit migration; physical-port
waveforms target the port rather than owned landings. Directional mesh and nonempty
live exclusion settings require an updated reader. Old result fields retain their
original identities. See [scientific acceptance](../scientific-acceptance.md).

Thickness-averaged models exclude full 3D spreading, breakdown, trapping, electrical
RLC storage and switching dynamics. The GaN conductance floor is not predicted
off-state leakage. SiC drawings do not create a gate-dependent transistor model.
Sparse factorization remains serial; more CPUs do not guarantee faster complete
runs. Native executable checks establish build-host behavior, not clean-machine,
physical mixed-monitor DPI or screen-reader certification.
