# Historical engineering notes — 0.2.0

Pre-public application version, 11 October 2026. The earlier distribution was
GPL-3.0-or-later; earlier recipients retain those rights. These notes do not
announce a public tag or public binary. Use the [current README](../../README.md)
for source installation and [licensing](../licensing.md) for redistribution.

## Scope

- Layer/region result selection, synchronized comparisons, manual colormap ranges,
  profiles, probes and export context.
- Backward-Euler thermal storage with quasi-static electrical feedback; pulse/PWL
  heat, current, voltage and gate drives; event-aligned time steps.
- Uniform/steady/saved-state initialization, same-mesh continuation, retained peak
  fields and cumulative input/output/stored energy.
- Mesh/time refinement at a common requested horizon, optional periodic detection,
  consistent or lumped heat capacity, bounded archives and configurable CPU studies.
- Larger example gallery, analytical walkthroughs and offline handbook.

## Compatibility and limits

The older four-part ribbon is documented in the [historical quick start](../user-guide.md).
Current controls use the [guided workflow](../desktop-workflow.md). Electrical
operation is steady; transient electrical states are quasi-static inputs to heat
flow. No electrical capacitance/inductance, switching overshoot, phase change or
adaptive error-controlled time integration is established. Saved-state replay
requires compatible source identity and the original mesh. See
[transient operation](../handbook/transient.md) and [validation](../validation.md).
