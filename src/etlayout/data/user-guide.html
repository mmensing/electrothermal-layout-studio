Setup: define the physical model

  1. Open Layers & Materials. Assign geometry, project material, thickness, bottom elevation and role to each sheet. Complete model tables and Materials and library remain under Model.
  2. Define electrical and thermal interfaces over the real overlap or via footprint. Projected overlap alone does not connect layers.
  3. In Contacts & Connections, choose external port, interlayer contact, passive probe, floating electrode, gate or boundary terminal before placing geometry. A port may own several local landing footprints. Positive current enters the device. Total current uses A; distributed current density uses A/m². On an edge the density is integrated over edge length × sheet thickness.
  4. Operating Conditions groups electrical inputs, port drives, thermal boundaries, heat sources and initial conditions. Supported thermal conditions include fixed temperature, ambient conductance/resistance, insulation and prescribed total W or W/m² heating. A steady thermal problem needs a heat-removal path; transient adiabatic heating can store energy without a sink.
  5. Mesh & Checks and Simulation → Numerical settings expose supported mesh sizes, solver tolerances, engineering warning thresholds, presets and notes. Numeric forms accept engineering units, for example 20 mV, 2 µm and 25 µs.

Common fields appear in the inspector, with advanced settings still reachable. Apply commits to the shared project and undo history; Cancel discards the draft. Leaving a dirty inspector offers Apply, Discard or Stay. Model tables and the embedded study workspace use the same document.

Layers & Materials → Technology templates… saves/loads portable .etltech.json physical mappings. Choose which layers to import and map each required template mask to an actual source mask, then Preview. The proposal shows file hash, source project, material provenance and added objects; Apply requires confirmation. Existing layers/materials stay intact, and unused source masks stay display-only. Templates copy physical layer models/material snapshots and declared contacts, not project terminal drives, thermal boundaries, heat sources or waveforms. Project-specific gate-terminal bindings are omitted explicitly; review gate conditions after applying. Template provenance is retained in project notes, and the complete application is undoable. Mesh/solver presets remain a separate task.

Explicit passivation and heat-source depth

Insulator and thermal layer roles conduct heat and store thermal energy without DC conduction. Set measured lateral conductivity, x/y anisotropy, optional through-plane conductivity, density and heat capacity in the material editor. Use adjacent stack thermal links: each includes its two endpoint half-thickness resistances. Replace the old effective material-filled gap when adding an explicit dielectric; retaining both double-counts the path. Open the Cross-section tab to inspect roles, thickness, z position, nominal conductivities, reservoir boundaries and effective gaps.

Finite interface/device-load loss defaults to 50% on each endpoint, preserving old calculations. The interface editor permits an explicitly configured Heat to layer A fraction, or a named Heat layer receiving all loss at identical planar support. The named layer must cover the full interface; keep the endpoint fraction at its default 0.5 when using that alternative. No electrical loss is changed, and no internal three-dimensional temperature profile is resolved. SiN, SiO₂, Al₂O₃, AlN and polyimide seeds are uncalibrated engineering/synthetic assumptions; replace them with process data before making device claims. See docs/thermal-stacks.md for measured comparisons and limitations.

CPU settings and background calculation

Edit → Execution settings… contains Total CPU thread budget and Parallel study worker limit. Both default to four, capped at the available logical CPU count; workers cannot exceed the total budget. Larger electrical and thermal assemblies use bounded worker threads. Native numerical kernels use one thread per worker throughout a run to avoid nested teams and short-vector overhead; Gmsh receives the selected meshing budget. Independent sweep, design, mesh and time-step study points divide the assembly budget across separate processes. For example, four CPUs and two active study points allow up to two assembly workers per point. More simultaneous points also need more memory.

Preparation and simulation run in the background so the desktop controls remain available. Cancel stops an active calculation and its study workers. Small assembly batches, geometry work and SuperLU sparse factorization remain serial, so CPU activity varies by phase. Results record actual assembly batches, worker IDs, CPU/wall time and the native one-thread cap separately from the configured budget. More CPUs do not guarantee a faster solve. Preferences apply to future jobs, are saved on this computer and recorded separately from project physics. GPU acceleration is not included. The CLI reports available CPUs and native thread-control support with etlayout.exe capabilities.

Pulse settings: timing, waveforms and advanced controls

Select a transient analysis in the header and open Simulation → Time and load settings, also reachable from Operating Conditions. Timing contains stop time, maximum step, saved-field interval and initialization. Waveforms contains readable source names, constant/pulse controls, a piecewise-linear time/value table and a preview. Advanced contains storage budgets, peak retention, Thermal capacity and optional periodic convergence.

Thermal capacity offers consistent or lumped discretization. Consistent P1 capacity is the default and may undershoot a physical temperature bound under localized short pulses. Lumped capacity reduces this risk, but adverse mesh or interface coefficients can still defeat monotonicity. Read the diagnostic and check mesh/time refinement; energy balance alone does not prove physical bounds.

A waveform replaces the selected static source value. Undriven values remain constant. Pulse width means the high plateau; rise + plateau + fall must not exceed the period. A zero period means one pulse. Thermal dynamics do not model electrical capacitance, inductance or switching overshoot.

Maximum step controls integration accuracy. Pulse edges, waveform knots and saved output times split integration steps. Hold the output interval fixed during a time-step refinement study. Initial fields at t=0 use the right-hand drive; subsequent fields at an ideal edge use the incoming interval's left-hand drive. The selected-time label and export metadata identify this convention.

Initialize uniformly, solve a steady initial bias, or use Simulation → Start transient from saved state. Resume saved transient continues from its accepted time to an absolute stop time and retains cumulative energy accounting. Saved fields must be compatible with the current geometry, mesh and thermal model; incompatible states are rejected.

Periodic convergence is optional and uses repeated temperature agreement at a common phase of equal-period pulse drives. It reports an early-stop reason and actual end time. It does not establish time-step accuracy; compare refined runs separately.

Inspect: keep spatial and temporal scope explicit

Choose layer, field and support in Results. Each field maps one layer's solved support. Regions can select islands or named terminal, source, interface and boundary footprints. The selection controls maps, vectors, mesh, probes, profiles, statistics and displayed-field exports. Holes and unavailable fields stay unpainted. Isolate layer hides unrelated geometry; turn it off for context. Fit layer frames the active field.

For transient results, use the saved-time controls or enter a time to choose the nearest retained field. Peak selects the retained whole-run temperature peak when peak retention is enabled. The spatial Hotspot command locates the maximum of the currently displayed quantity and region. Whole-run warnings remain visible while inspecting cooler frames.

The retained results controls include time history with Whole device, Selected layer / region and Map probe scopes. Whole-device scalar history includes every accepted step. Local traces are derived from retained fields: sparse output can miss a local peak. Click a trace to select its nearest retained map frame. Exporting a scoped trace records that selection.

Results display settings retain Appearance and Compare controls. Choose Teal, Viridis, Magma, Cividis, Coolwarm or Grayscale. Manual range accepts unit-aware limits; Auto uses finite support. Across-time limits retain a common scale across snapshots. Log scale needs positive values. Smooth interpolates nodal fields; vectors show normalized directions. Color clipping never changes numerical values.

Compare layers synchronizes field, time, palette, scale and optional physical pan/zoom; each panel can select a layer and region. Run comparisons expose linked nearest-time or independent time selections and record both actual source times, including when saved grids differ. Difference fields retain finite common support. A comparison's time match is a sampling choice, not time interpolation.

Probe a point, draw line profiles or draw a cross-section through physical layer occupancy. Profiles preserve gaps. Branch current integrates a directed cut; positive flux points toward its left normal. Run history retains configurations and opens a marked read-only inspection context. Return to current project restores editing.

Probing reports in the status bar and updates the time trace without opening another panel. Timeline dragging coalesces updates and reuses cached history ranges; the first across-time range calculation can still take time for a large history.

Engineering evidence and linked hotspots

Results offers Check mesh sensitivity… and, for transient runs, Check time-step sensitivity…. These open the existing studies for the current applied physical setup. Historical runs stay read-only: return to the working setup before starting a study. Mesh studies compare global integrals, configured regularized metrics and selected drawn profiles; a chosen map region or pixel is not automatically verified.

Results → Metrics & loss budget → Engineering groups independent numerical, conservation, hard-temperature-limit, material-range, mesh/time and calibration evidence. Device & losses reuses recorded device groups, contact loading, transfer-length estimates and the disjoint power ledger; groups are not additional losses.

Same support → Inspect same support integrates E, K, physically defined metal J, heat, T and ΔT over the selected layer/region or a fixed square around the last probe (side in µm). Partial elements and holes retain exact support. Double-click a quantity to select its map and outline; Locate marks the unqualified raw current peak. Changed runs/frames require fresh inspection. Generated interface loss differs from allocated sheet heat. A mesh receipt applies only to matching support and cannot establish fabricated-radius or material calibration.

Transient navigation separates displayed time/Tmax from accepted-run peak/time. Peak frame opens a retained peak field; Last frame returns to the last accepted saved state. Nearest to peak states when its spatial field is absent. Segment peaks and incomplete requested duration remain explicit even when the last PDE state converged.

On-demand history: load the fields you choose

Create File → Save content-addressed copy… first. In Edit → Archive and history settings…, enable Open schema-3 history on demand and reopen that copy. This opening mode is opt-in and applies to the next opening; schema-1/2 archives and legacy JSON keep eager loading. Results → Inspect saved runs opens read-only history; Return to working setup restores the editable document and its view.

File Open reads every supported format in a background worker, including default eager loading. The working setup stays available until opening and resource review finish. Cancel the read in History to retain it; cancelled or superseded replies cannot replace a newer working or historical context. Normal draft and unsaved-change decisions still apply.

Opening checks metadata in a background worker and keeps an immutable private disk copy of the selected archive. Runs list their original configuration and stored convergence before all numerical fields load; a stored badge does not certify unloaded fields or mesh verification. Selecting a transient time loads its exact retained frame and shared mesh. Failed or cancelled reads keep the previous usable view and explain the problem in Issues.

The array-cache default is 256 MiB, adjustable from 16 to 8,192 MiB in the same settings dialog. History reports unique resident/pinned array payload bytes and active reads. These are not process RSS; metadata, temporary buffers and the private disk copy are separate. Active views and comparisons pin their arrays. Only unpinned arrays can be evicted; a larger selection asks for explicit temporary over-budget approval or cancellation.

Whole-device scalar charts use recorded metadata. Local traces, whole-history color limits, comparisons and complete numerical exports explicitly load the complete supports they need; Load complete time history… requests retained transient fields. Selected figure/data exports keep their reviewed layer, support and time scope. Complete Save and Archive complete experiment include retained runs and frames never browsed, using worker-held source leases. Progress and cancellation remain available; cancellation before atomic publication preserves the previous archive. The private copy is removed after its readers and save/export leases close.

Studies: check discretization and controlled changes

Mesh & Checks → Suggest local refinement prepares reviewable contact-transfer, gated-channel, narrow-island and physically averaged hotspot sizing. Preview and Cancel preserve the working setup; Apply is undoable. A bounded local study uses two to four decreasing factors, keeps global sizing and physical averaging lengths fixed, and compares resistance, delivered current, like-sized device-group sharing and regularized hotspots. Levels run serially with the selected CPU thread budget. Element/DOF limits remain enforced by the mesher; the additional numerical-memory screen excludes process baselines and does not guarantee peak RSS. Successive changes are empirical mesh sensitivity, not an automatic verified badge. The CLI shares this workflow through mesh-plan and refine --local-plan.

Studies offers parameter sweep, mesh and time-step convergence, project comparison, routing and optimization, and saved study results. Time refinement keeps output interval fixed and uses one verified common mesh in all workers, preserving cold/saved/resumed initial states. It reports peak temperature, peak time, generated/exported/stored energy, energy imbalance and changes between steps; incomplete or mismatched histories do not receive temporal confidence. Periodic early stopping is disabled for the study so runs share an end time.

Parameter sweeps record requested and applied values. Sweep a waveform amplitude through its waveform path, not the static source it overrides. Ideal corner current peaks are mesh sensitive; compare integral quantities and physical profiles as well.

Mesh and time refinement compare the same requested duration with periodic early stopping disabled. Failed study points retain a visible status and do not connect successful curve segments. Saved-state studies reuse the source mesh; changing its geometry or mesh requires uniform or steady initialization. Source-bound presets require their original state or an explicit initialization change.

E27 contact extraction: open E27, then choose Studies → Finite-contact TLM study (E27)…. Select a parent folder; the GUI creates a new empty child directory for four actual finite-contact coupon calculations, editable solved projects and the fit. TLM output must be empty: a folder containing existing work is rejected. The cancellable background job preserves the working setup. Inspect fitted sheet/contact resistance, specific contact resistivity, transfer length, individual observations and the finite-length contact reference. Fit residuals/covariance describe numerical scatter, not experimental calibration or full discretization uncertainty. This is linear TLM, not CTLM.

E40 fixture separation: Results → Device and fixture observations… reports internal loss and feed-deembedded operating-point P/I² separately from external feed power. Remove the entire feed electrical loss when deembedding; its declared locally deposited fraction still enters the thermal balance. A scalar resistance is unavailable for an unestablished multiport service. These synthetic cases do not establish current ratings or calibrated transistor performance.

Original solver metrics and history remain unchanged.

Select fixed physical averaging windows when comparing hotspots. Empty or stale selections are unavailable. Physical vias validate stack height, landing enclosure and dielectric replacement. Effective couplings preserve their declared assumptions.

Experiments compare the same current/service requirement across all scenarios, preserve fixed active geometry and report failed candidates explicitly. Coarse feasibility is provisional. Measurement support retains exact clips through nested device groups. Passive SPICE export retains weak connections and rejects unestablished per-port fidelity. Via width and transition-wide pitch/spacing use actual geometry. See docs/scientific-acceptance.md.

Save, export and recover

Schema 2 remains the default portable archive and automatic-recovery format. File → Save content-addressed copy… explicitly creates schema 3, sharing identical layout, mesh and field objects within that self-contained file while retaining distinct run identities. Normal Save retains the chosen format; opening never converts a file. Keep the original or use Save legacy-compatible copy… for older readers. Storage choices do not change physics or numerical precision.

Results → Export task offers three purposes: Share figure or report (PNG, vector PDF/SVG, standalone HTML), Share selected numerical data (CSV/NPZ/VTU), and Archive complete experiment (confidential ETL with source layout, setup, materials, fields and history). Use Selection & scale, Figure & report and Files & review. Choose layer, quantity, named support, retained time and optional exact rectangle; then review the files and information before exporting. Changes revoke the previous review.

Sharing is enforced by the backend: only selected FE support and small interpretation metadata are included. Partial triangles are geometrically clipped and P1 values interpolated; raw values stay SI and unclipped. Source layout, complete configuration, project notes, unrelated fields, history and machine paths are excluded. Selected geometry can still reveal your design. Figure controls include dimensions, PNG DPI, PDF page/orientation, legend/colorbar, smooth/flat presentation, range/palette and explicitly entered title/annotations. Source warnings, time, physical aspect and units remain visible. Small figures/long annotations are rejected if caveats would not fit.

HTML embeds generated PNGs, treats metadata as text and blocks scripts/remote resources. CSV protects formula-like text with an apostrophe while numeric negatives and scientific notation stay numeric. Complete numerical bundles and the legacy Python export API remain comprehensive, even for filtered calls: they may include the full layout, notes and physical setup. A cropped graphic does not crop that archive. File → Save project retains the working setup; sharing exports do not change it.

Review exact contents before writing. Existing filenames are rejected unless replacement is explicitly selected. Temporary sibling export files are cleaned up; replacement is atomic per artifact, not across a bundle, and its manifest is last. Do not treat source convergence as mesh verification. Candidate-layout and passive multiport exports stay in their owning studies.

Physical edits invalidate the current result while keeping recorded runs. Display changes and notes preserve fields. Recovery runs every minute when changes are unsaved. A recovery warning identifies write failures. View can save, restore and reset dock layouts or select Dark theme. Time-history plots follow the theme; other scientific plots retain white canvases.

Each window owns a unique session and snapshot; startup lists interrupted projects individually with Recover, Ignore, Discard (confirmation) and Open original. Active sessions are excluded. A normal save removes only this session’s snapshots through the saved revision. Recovery archives in the local recovery directory contain full, unencrypted project data; failed cleanup can leave a redundant copy.

Saving runs in a dedicated worker with visible progress and Cancel save. New edits remain dirty until their own revision is saved. The previous archive is preserved on a failed or cancelled write; Save As changes the filename only after success. Opening JSON metadata keeps its source intact: Save offers a portable .etlayout destination, and archive saving rejects JSON filenames. While inspecting History, Save writes the working setup; Cancel, a cancelled Save As chooser, and a failed save preserve the inspected view. A destination changed after submission, including while queued, is rejected. Wait for save completion before closing or opening another project.

The run-history panel shows retained-data estimates and, in on-demand mode, array-cache usage; it allows removing selected runs. Saves check the complete expanded archive budget before replacing an existing file. A rejected save preserves the previous archive. Remove unneeded saved runs, or rerun with a longer saved-field interval and remove the superseded larger run before saving. Changing the interval affects future solves; it does not thin fields already retained in a result. Exported transient histories include the initial-state source, segment time interval, cumulative-energy scope, peak scope and stop reason, including in the CSV metadata sidecar.

Physical scope and interpretation

The model uses thickness-averaged 2.5D sheets with declared vertical transfer. Density and specific heat supply thermal mass; interfaces have no separate heat capacity. Through-thickness transient diffusion, electrical RLC dynamics, phase change and adaptive time stepping are not modeled. Representative materials require calibration. The effective HEMT model excludes drift-diffusion, trapping, breakdown and field-plate electrostatics. Engineering warning thresholds remain warnings. Operating conditions → Maximum operating temperature provides separate optional hard limits in °C/K: equality or exceedance fails engineering acceptance while retaining converged fields. Transients may stop at the first violating accepted state; this sample time is not an exactly localized crossing. Numerical convergence, conservation, mesh/time verification and material validity remain independent.

Project resource trust

Opening inspects metadata before accessing declared layouts. Embedded resources open normally; outside-root files require authorization and network locations require a separate opt-in. File → Review project resources offers authorize, relink, leave unresolved and cancel. Unresolved projects retain editable settings while geometry, Run and portable saving remain blocked. Approval applies only to this opening. CLI users can inspect declarations with etlayout project-info and grant --allow-outside-root and --allow-network separately. Embedded sources use a validated local temporary SHA-256 cache, removable when not in use.
